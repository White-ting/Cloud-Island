# 云岛 Cloud-Island

给 AI 伴侣用的手机聊天页 + 记忆库后端。后端零依赖（只用 Node 自带的模块），在你自己的电脑上跑，聊天记录、记忆这些数据存在你自己的硬盘上。

存在本机不等于不外发：你接的模型、语音、翻译、推送这些服务，会收到对应的内容（见下面「隐私提醒」）。

> 名字的意思：湖心的一座小岛。念想涨起来的水围着岛，云是这一切开始的那个 TA。

作者：White-ting · 版本 v1.0（2026-11-18）· 许可见 [LICENSE](LICENSE)

这是**公开源码版**：源码公开，但许可不是开源许可——自用自改，不许转发、不许商用。

## 能做什么（v1）

- **聊天**：接各家 API 的模型（OpenAI / Responses / Anthropic / Gemini 格式），流式回复、重新生成、多个版本、引用、Markdown；思考和工具调用收成一行，点开看时间线；英文思考可以一键翻成中文（要配翻译模型）。
- **人格**：每个 TA 一份人格设定，能看旧版、能回退。
- **记忆库**：TA 自己记、你也能记；待整理的你看得到、能更正；私人念想；召回时按相关程度挑，最像的给全文、特别像时顺着连线带出连着的几条，TA 也能自己点开一条细看（可选接本机向量模型）；记忆锁。
- **夜里**：到点让一个临时的 TA 回头整理记忆、写日记、写梦（各有开关）。可以再接一个**记忆小模型**先替它翻一遍材料：给记忆打标、挑可能是同一件事的、提醒到日子的事，写一份「对她的印象」草稿，拿主意的还是夜里的 TA；印象收下以后，开场会带上（默认关，见 `docs/接口-新增.md` 第 9 节）。
- **召回带日期**：想起来的每一条都标着哪天记的（今年的写月-日，往年的写全），TA 能说「8 号那次你也是这样」。
- **主动找你**：敲门（外部事件叫醒 TA，由 TA 自己决定说不说）、空下来、回头看；默认都关。
- **记忆网关**：别的 App 填网关地址，聊天时自动带上记忆再转给模型。
- **Claude Code 示例钩子**：让命令行里的 Claude Code 也读写同一个记忆库（`examples/claude-code/`）。
- **发语音、打电话**：你按话筒发语音（转成字给 TA），或者在网页里打电话（一句一轮）；TA 用你选的声音说话（ElevenLabs、Cartesia、MiniMax，或任何 OpenAI 兼容的语音接口）。
- **推送**：网页推送（加到手机主屏幕后可收），也可以用 Bark。
- **开屏字幕**：打开时按时段显示一句 TA 写的话；没有就显示时间问候。
- **DeepSeek Harness（dsh）**：名单里可以有一个 dsh 的 TA，它能在你电脑上读写文件、跑命令。它在工作目录里写文件、跑命令一般不问；要做超出权限的事（比如写工作目录外面）时，dsh 会发起确认，你在手机上点允许或拒绝（见 `docs/接口-dsh.md`）。
- **外观**：猫头鹰桌宠、水面、几种背景、主题色；开屏中文用霞鹜文楷。
- **网页口令**：可选，强烈建议开。

### 以后的版本

- **接 tmux 里的 Claude Code**：云岛本来能接在终端里跑着的 Claude Code，手机上像直接在用它（作者自己天天这么用）。这个模块跟机器绑得比较紧，公开源码版以后再整理放出来。
- 便签墙、日历待办、仓库、群聊：私用版有，v1 先不放。

## 装

要 **Node 20 或更新**（用 dsh 的话要 Node 24.9 或更新）。不用 `npm install`，没有依赖。

1. 下载这个仓库（GitHub 页面上 Code → Download ZIP，或 `git clone`）。
2. 在仓库文件夹里，把 `.env.example` 复制一份改名 `.env`，照里面的说明填。至少要填：
   - `HOOK_TOKEN`：终端里跑 `openssl rand -hex 24` 生成一串贴进去（只给钩子、守门人用，不能拿它登录网页）；
   - 你要用的模型的 key（比如 `AI_DS_KEY=…`），名字自己起，跟下一步 ais.json 里的 `keyEnv` 对上。
3. 启动：`node backend.mjs`（或 `npm start`）。看到「后端 1.0.0 已启动」就好了。
4. 写你的 TA 名单：在仓库文件夹里建一个 `data` 文件夹（`.env` 的 `DATA_DIR`，默认就是它），里面新建 `ais.json`，比如接 DeepSeek 官方：
   ```json
   [{ "id": "ds", "name": "小深", "model": "deepseek-chat", "style": "openai", "url": "https://api.deepseek.com", "keyEnv": "AI_DS_KEY" }]
   ```
   `keyEnv` 写的是 `.env` 里放 key 的那个名字，key 本身不写进这个文件。更多写法（Claude、Gemini、思考、上下文长度）见 `.env.example` 里「聊天」那段；dsh 的 TA 见 `docs/接口-dsh.md`。后端每次都现读这个文件，改完刷新网页就行，不用重启。
   这份名单只能在这台电脑上手改：里面写着用哪个 key、往哪发、dsh 拉起什么程序，所以网页和接口都改不了它。
5. 电脑上打开 `http://127.0.0.1:18400/`，顶上就是你的 TA。

### 在手机上用

后端默认只听本机。没设 `WEB_PASSWORD` 时，网页只能在这台电脑上用 `localhost` 或 `127.0.0.1` 打开。要在手机上用：

1. **先设 `WEB_PASSWORD`**（必须）。
2. 二选一：
   - **同一个 Wi-Fi / Tailscale**：`.env` 里 `HOST` 改成电脑的局域网地址或 Tailscale 地址（或 `0.0.0.0`）。用 IP 打开不用别的设置；用名字打开（比如 Tailscale 的 `xxx.ts.net`）要把这个名字写进 `ALLOWED_HOSTS`。
   - **Cloudflare 隧道**：把 `http://127.0.0.1:18400` 用隧道发出去，最好前面再加一道 Cloudflare Access；隧道的域名写进 `ALLOWED_HOSTS`，`TRUST_PROXY=127.0.0.1`（登录限速才认得出每个人）。

后端只认白名单里的地址（Host），别的网站把自己的域名解析到你电脑上也进不来；会改东西的请求还要是从这个网页发出来的。

然后在 iPhone 的 Safari 里打开，分享 → 添加到主屏幕，就像一个 App；要收推送也得这样加。

### 数据在哪、怎么备份

要备份的有这几样，别把它们传到网上：

- **`DATA_DIR`**（默认 `data/`）：聊天记录、记忆、日记、设置、名单 `ais.json`。key 只写在 `.env` 和 `data/svc.json`（权限 600）。
- **`.env`**。
- **dsh 的 home**（用了 dsh 才有，`ais.json` 里 `dsh.home` 写的那个文件夹）：dsh 的会话存在这里，`data/` 里只记着「现在续的是哪个会话」。只备份 `data/` 的话，恢复后接不上原来的会话，只能开新会话。
- **dsh 的工作目录**（`dsh.workspace`）：dsh 在里面写的、你想留的东西，自己另外备份。

## 隐私提醒

- 数据存在本机，不等于不外发。你填的模型、向量、翻译、夜里整理、语音服务，填了云端的地址，对应的文字（聊天、记忆、思考、语音）就会发给那一家；推送也一样：网页推送经过苹果、谷歌这些推送服务（内容加密），Bark 发给 Bark 的服务器（不开加密时是明文）。能用本机的就用本机的。
- 记忆小模型打开后，夜里会把记忆（私人念想除外）发给你填的那个模型；`talk` 打开的话，最近 24 小时的对话原文也会发过去。
- 网页设置里填的地址默认只许 https 的公网地址；本机的服务（比如 Ollama、本机语音）、局域网的服务、自建的 Bark 服务器，要在 `.env` 的 `ALLOW_URLS` 里放行。Key 只发给存 Key 时填的那个地址，换了地址要重新填 Key。
- dsh 能读写文件、跑命令：给它一个单独的工作目录，别指到你的主目录。权限默认 `workspace-write`：工作目录里的事不问就做，超出权限的才发起确认。它默认会把会话日志传给 DeepSeek 官方，云岛启动 dsh 时会帮你关掉（见 `docs/接口-dsh.md`）。
- 退出登录会让这一个登录作废（复制走的同一个 cookie 也不能再用）；想让所有设备都掉线，改 `WEB_PASSWORD` 或 `SESSION_SECRET` 再重启。
